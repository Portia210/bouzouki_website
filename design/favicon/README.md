# Favicon work

Current icon: amber pick (outline from `originals/pick-photo.png`, colour from `originals/color-sample-amber.png`) on a deep-blue tile.
Rebuild or change variant: `uv run python design/favicon/make_icons.py deepblue|pearl|blue|black|night` (preview: `... sheet`).

- `originals/` — images the developer supplied (Greek bouzouki reference, the liked tilted bouzouki, the pick photo, the colour sample) and the first site logo.
- `attempts/bouzouki-drawn/` — hand-drawn SVG bouzouki icons and their generators (ornate, flat, B monogram, plectrum).
- `attempts/pick-drawn/` — hand-drawn pick-shaped SVGs (tortoiseshell, blue, black).
- `sheets/` — comparison sheets, numbered in the order they were made.
- The large upright bouzouki used on the home page is `static/img/logo.svg`.
